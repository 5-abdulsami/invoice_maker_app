# Bundled font licences

Every typeface shipped in `assets/fonts` may be embedded in the PDFs the app
generates and redistributed with the app.

| Files | Family | Licence |
| --- | --- | --- |
| `roboto-*`, `robotocondensed-*`, `robotomono-*` | Roboto, Roboto Condensed, Roboto Mono | Apache License 2.0 |
| `serif-*` | KaTeX Main (Khan Academy) | MIT, see `KaTeX-MIT.txt` |
| `abrilfatface-*` | Abril Fatface | SIL OFL 1.1, see `OFL.txt` |
| `librefranklin-*` | Libre Franklin | SIL OFL 1.1, see `OFL.txt` |
| `rubik-*` | Rubik | SIL OFL 1.1, see `OFL.txt` |
| `lato-*` | Lato | SIL OFL 1.1, see `OFL.txt` |
| `oswald-*` | Oswald | SIL OFL 1.1, see `OFL.txt` |
